Outlook (new Outlook, Outlook on the web, Mac)
  1. Settings (gear) → Accounts or Mail → Signatures.
  2. Click New signature, name it The SocialDM.
  3. Click in the box and paste (Command + V).
  4. Set it as default for New messages and Replies/forwards, then Save.
iPhone Mail
  1. Open this page on your iPhone, tap Copy signature.
  2. Settings → Apps → Mail → Signature, paste.
Gmail
  1. Settings → See all settings → Signature → Create new, paste, Save.
